# 2D-Unity-Platformer
Пример моих скриптов из моего 2D-платформера

### 📂 Исходный код проекта:
* 🏃‍♂️ [PlayerMovement.cs](Scripts/Movement/PlayerMovement.cs) — обычный CharacterController, отвечающий за передвижение персонажа, звуки и анимации. (Самый жирный скрипт в игре)
* 🌌 [BackgroundMovement.cs](Scripts/Environment/BackgroundMovement.cs) — скрипт бесконечного параллакса фона.
* 🛑 [Groundcheck.cs](Scripts/Movement/Groundcheck.cs) — триггер детекта приземления.

<details>
<summary>📦 Показать остальные вспомогательные скрипты проекта: </summary>
<br>
  
* 🛠️ [WallDetection.cs](Scripts/Movement/WallDetection.cs) — датчик соприкосновения со стенами для механики Wall Jump.
* 🎵 [CameraMovement.cs](Scripts/Movement/CameraMovement.cs) — скрипт передвижения камеры за персонажем.
* 🕒 [LevelChanger.cs](Scripts/Environment/LevelChanger.cs) — смена уровней при триггере объекта.
